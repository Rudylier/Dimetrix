<h1 align="center">Dimetrix</h1>
<p align="center">Диагностика домашней сети для Windows — в один клик и без установки.</p>

---

> **Только для Windows 10/11.** На macOS и Linux Dimetrix не запустится: `Dimetrix.exe` и `Dimetrix.cmd` — файлы Windows, а проверки используют системные команды Windows.

Dimetrix проверяет, почему «тормозит интернет»: VPN, прокси, пинг, DNS, скорость, программы, которые копят сетевые соединения, и доступность популярных сайтов. Всё показывает на понятной странице с подсказками, что делать.

**Ничего не меняет в системе** — только читает состояние и делает замеры.

## Возможности

**Обзор сети**
- **Подключение и VPN** — через какой адаптер идёт весь интернет (напрямую или через VPN).
- **Системный прокси** — используется ли прокси или PAC-сценарий (например, от рабочей сети) и отвечает ли он.
- **Пинг и потери** — роутер, Cloudflare, Google, Яндекс; подсказывает, где начинаются потери: в Wi-Fi/кабеле или у провайдера/VPN.
- **DNS** — как быстро находятся адреса сайтов.
- **Нагрузка сейчас** — сколько этот компьютер качает прямо сейчас.
- **Соединения программ** — подсвечивает программы, которые копят сотни соединений и «вешают» интернет.
- **Скорость** — загрузка и отдача через speed.cloudflare.com (~100 МБ трафика, можно пропустить).
- **Автозапуск VPN** — какие VPN и прокси стартуют вместе с Windows.

**Сайты и приложения** — 20 сервисов одной кнопкой (и в составе «Проверить всё»), параллельно, за ~8 секунд: YouTube, Twitch, TikTok, Telegram, WhatsApp, Discord, ВКонтакте, Instagram, Facebook, X, ChatGPT, Claude, Cursor, Steam, Epic Games, Spotify, Яндекс, Google, GitHub, Госуслуги. Для каждого видно, какие адреса открылись, за сколько и почему нет («таймаут», «сброс соединения — похоже на блокировку DPI», «DNS»).

**История** — каждая полная проверка сохраняется; графики пинга и скорости во времени, удаление записей.

**Пинг-понг** — пока идёт проверка, можно сыграть в минималистичный пинг-понг против Dimetrix прямо на главном экране — над полем видно, сколько процентов проверки готово и какой шаг идёт (мышь или ↑ ↓, пробел — пауза).

**Отчёт** — скопировать или сохранить в `.txt`, чтобы отправить в поддержку провайдера.

## Запуск

1. Скачай архив проекта (**Code → Download ZIP**) и распакуй.
2. Запусти **`Dimetrix.exe`** — он лежит прямо в распакованной папке, рядом с папкой `app`. Откроется окно с интерфейсом.

`Dimetrix.exe` должен лежать рядом с папкой `app` — не переноси его отдельно (для рабочего стола сделай ярлык). Если Windows покажет «Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**: exe не подписан. Запасной способ запуска — `app\Dimetrix.cmd`.

Нужны **Windows 10/11** (macOS и Linux не поддерживаются) и Google Chrome или Microsoft Edge (окно открывается в режиме приложения).

## Как устроено

```
Dimetrix.exe         запускатор с иконкой (стартует app\Dimetrix.ps1 без окна консоли)
app\Dimetrix.ps1     все проверки + маленький локальный веб-сервер
app\Dimetrix.html    интерфейс
app\*.png, *.ico     логотип и иконки
src\Launcher.cs      исходник запускатора
build.ps1            сборка Dimetrix.exe встроенным в Windows компилятором C#
```

- Сервер слушает только `localhost`; каждый запуск получает случайный ключ доступа, без него сервер не отвечает.
- Сервер сам выключается примерно через 40 секунд после закрытия окна.
- История хранится в `%APPDATA%\Dimetrix\history.jsonl` (последние 300 проверок) — не в папке проекта.
- Наружу уходят только сами проверки: пинги, DNS-запросы, обращения к проверяемым сайтам и к speed.cloudflare.com. Никакой телеметрии.

Режим без окна, с выводом в консоль:

```powershell
powershell -ExecutionPolicy Bypass -File app\Dimetrix.ps1 -Console
```

## Сборка Dimetrix.exe

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Используется `csc.exe` из .NET Framework 4, который есть в любой Windows 10/11.
